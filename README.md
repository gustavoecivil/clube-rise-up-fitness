# Rise Up Fitness — site institucional

Site responsivo do estúdio Rise Up Fitness, com identidade visual da marca, apresentação de Dani Dias e os serviços: Pilates Solo, Treinamento Funcional, Massoterapia, Acupuntura e Estética.

## Treinamento personalizado

A página informa exclusivamente os quatro valores anteriormente atribuídos à equipe da Dani:
- Aula avulsa: R$ 100,00 por aula.
- Individual: R$ 85,00 por aula, contratação mensal.
- Dupla: R$ 60,00 por pessoa/aula, contratação mensal.
- Trio: R$ 45,00 por pessoa/aula, contratação mensal.

Não há planos Rise/Plus/Premium, mensalidades inferidas, simulador, cupons, descontos ou regras adicionais de reposição/férias. Não pressupomos valores de Pilates Solo e demais serviços.

## Publicação
- Página inicial: `index.html`.
- Este repositório armazena uma versão HTML de arquivo único, com as imagens incorporadas.
- Para Netlify foi produzido também um pacote ZIP com `index.html`, `styles.css`, `script.js` e `assets/`.
- Domínio registrado pelo usuário: `estudioriseup.com.br` (ainda sujeito à configuração DNS no Netlify).

A imagem original de Dani Dias é usada sem alterar seu rosto. O mapa é vinculado a https://maps.app.goo.gl/1DRZGEsVUzfw1jKC9.
