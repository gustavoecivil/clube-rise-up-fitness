# Clube Rise Up Fitness — Painel interativo

Apresentação demonstrativa do Clube Rise Up Fitness, construída para GitHub Pages.

## Funcionalidades
- Comparador de mensalidades Rise, Plus e Premium; modalidades individual, dupla e trio; frequências 2x, 3x e 4x.
- Simulação de 1, 3, 6 e 12 meses, Pix mensal, Pix antecipado e cartão via link.
- Cenários de reajuste, permanência e procura, com probabilidades **hipotéticas/editáveis**.
- Simulador de massagens de 60 minutos, a partir de R$ 150 por sessão, e pacotes editáveis.
- Regras de horários, faltas, reposições, férias e pagamentos.

**Importante:** este é um protótipo público, não uma tabela aprovada pela direção. Não realiza pagamentos, não acessa cartões, não armazena dados de alunas e não oferece previsão estatística validada. O conteúdo precisa de revisão comercial/jurídica antes de venda real.

## Hospedagem
Publicação estática sem dependências de servidor e sem Netlify: `index.html` na raiz da branch `main`.

Para ativar uma única vez: GitHub → Settings → Pages → Source: **Deploy from a branch** → Branch: **main** → Folder: **/(root)** → Save.

Após GitHub Pages confirmar a publicação, o endereço será:
https://gustavoecivil.github.io/clube-rise-up-fitness/

## Atualizações
Novos commits na branch `main` republicam a página automaticamente após a ativação.

A arte usa o logotipo original fornecido, incorporado diretamente no HTML para dispensar arquivos de imagem externos.
